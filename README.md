# Flashcards

Веб-приложение для изучения английских слов методом **флэш-карточек с интервальными
повторениями**. Пользователь добавляет свои слова, повторяет их по карточкам и отмечает
«Знаю» / «Не знаю» — от этого зависит, когда слово покажется в следующий раз.

Индивидуальный итоговый проект по информатике (МБОУ СОШ № 23, г. Владивосток, 2026).
Автор — Шелудько Антон, 10 «Б». Руководитель — Чиркова А. Д.

---

## Зачем это

Новые слова быстро забываются, если к ним не возвращаться: это описывает кривая
забывания Эббингауза — сначала забывание идёт очень быстро, потом замедляется.
Значит, слово недостаточно один раз увидеть, к нему нужно возвращаться через
растущие промежутки времени. Приложение берёт расчёт этих промежутков на себя.

---

## Что умеет

- **Профиль по логину.** Логин записывается в адрес страницы (`?uid=...`), поэтому
  свой набор слов можно открыть с любого устройства по той же ссылке.
- **Добавление слов.** Пара «английское слово — перевод», всё хранится в базе.
- **Карточка для повторения.** Показывается слово, перевод открывается по кнопке —
  сначала нужно вспомнить самому.
- **Интервальные повторения.** Ответ «Знаю» удваивает интервал (1 → 2 → 4 → 8 дней),
  «Не знаю» сбрасывает его обратно на 1 день. Дата следующего показа считается от
  текущего момента.
- **Статистика.** Всего слов и сколько доступно для повторения прямо сейчас.
- **Список слов** с интервалом и датой следующего повторения, с возможностью удалить
  ненужное слово.

## Как работает

1. Пользователь открывает приложение и вводит логин.
2. Из базы загружаются его слова и прогресс.
3. К повторению отбираются слова, у которых `next_review` уже наступила.
4. Показывается карточка; пользователь вспоминает перевод и жмёт «Знаю» или «Не знаю».
5. Новый интервал и дата следующего повторения сохраняются в Supabase.

## Запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```

Приложению нужны ключи Supabase — без них оно не стартует. Создай файл
`.streamlit/secrets.toml`:

```toml
SUPABASE_URL = "https://<твой-проект>.supabase.co"
SUPABASE_KEY = "<anon / publishable ключ>"
```

При деплое на [Streamlit Community Cloud](https://share.streamlit.io) те же две
переменные задаются в настройках приложения (Settings → Secrets), файл в репозиторий
не кладётся.

### Таблица в базе

Один раз выполнить в SQL-редакторе Supabase:

```sql
create table flashcards_words (
  id          bigint generated by default as identity primary key,
  user_id     text not null,
  english     text not null,
  russian     text not null,
  interval    integer not null default 1,
  next_review timestamptz not null default now(),
  created_at  timestamptz not null default now()
);
```

## Что не сделано

Честно о границах проекта:

- **Нет настоящей авторизации.** Логин — это просто строка в адресе страницы, пароля
  нет, и чужие слова может открыть любой, кто угадает логин.
- **Интервал растёт по простой схеме** (умножение на 2), без учёта того, насколько
  трудно далось слово, — это упрощённая версия алгоритмов вроде SM-2.
- **Нет автоматического перевода и словаря** — перевод вводится вручную.
- **Повторяется всегда первое подошедшее слово**, порядок не перемешивается.

## Продолжение

Работа над проектом показала, что заучивание отдельных слов само по себе языку не
учит. Поэтому идея была переработана вокруг навыков чтения, письма и аудирования, а
карточки стали вспомогательным инструментом — это уже отдельный проект
[Eaglish](https://github.com/AntonShell7/eaglish), написанный с нуля.
